# TrainCrewMotorSound

TrainCrewMotorSoundは、溝月レイル/Acty様製作の列車運転ゲーム「TRAIN CREW」で動作する、BVE Trainsim用モータ音連動ソフトです。  
#### ※車両データは「BVE5」「BVE6」形式に対応しています。BVE4以前には対応していません。

![1](https://github.com/user-attachments/assets/57d7b18f-0b49-4ce4-b8a2-6ed587c1dca5)

# 使い方
1、TRAIN CREWの操作設定→外部デバイス入出力を「有効」に設定してください。

2、TRAIN CREWのサウンド設定→モータ音音量を「0」に設定してください。

3、Zipファイルを解凍後、TrainCrewMotorSound.exeをダブルクリックして起動してください。ファイルの解凍先は自由です。

4、[ BVE車両ファイル読込 ] ボタンをクリックして、ダイアログからVehicleファイルを選択します。

5、[ 情報 ] 欄の"モータ音読込"項目が [ 完了 ] になっていれば成功です。

# 操作説明

☑最前面表示  
　ウィンドウを最前面にするかどうかを設定します。  
　チェックを入れると最前面になります  

☑ノッチ連動  
　ノッチ操作と連動して音声を再生します。  
　チェックを入れるとノッチ操作に連動し、外すと速度情報のみで再生処理を行います。 

 ☑非常ブレーキ時回生オフ  
　非常ブレーキ操作時に回生モータ音を再生するかどうかを設定します。  
　チェックを入れると非常ブレーキ操作時に回生モータ音をオフにします。 

 ○回生失効速度  
　減速時にモータ音を停止する速度を指定します。  
　0km/h～120km/hまで選択できます。  

○走行音選択  
　Runファイルが用意されている場合に再生したいRunファイルを指定できます。  

# 自動走行モード

TRAIN CREWの速度情報を使わず、指定した条件で速度を自動的に変化させてモータ音・走行音を再生するモードです。  
TRAIN CREWが起動していなくても動作します。  

○加速度・減速度  
　加速時・減速時の速度変化を km/h/s で指定します。  
　0.1km/h/s～10.0km/h/sまで指定できます。  

○最高速度・下限速度  
　最高速度まで加速したあとは惰行し、下限速度を下回ると再び加速します。  
　惰行中は 0.1km/h/s ずつ速度が下がります。  
　下限速度は最高速度より低い値を指定してください。  

○終了条件  
　・走行時間：[ 開始 ] を押してからの経過時間を分・秒で指定します。  
　・終了日時：走行を終了する日時を指定します。  
　・指定なし：[ 停止 ] を押すまで走行を続けます。  
　走行時間・終了日時を指定した場合は、終了時刻にちょうど 0km/h になるように自動で減速します。  

○開始 / 停止ボタン  
　[ 開始 ] を押すと 0km/h から走行を開始します。  
　走行中に [ 停止 ] を押すと、指定した減速度で減速して停止します。  
　減速中に [ 即時停止 ] を押すと、その場で自動走行を終了します。  

※自動走行中は「ノッチ連動」「非常ブレーキ時回生オフ」の設定は無視されます。「回生失効速度」の設定は有効です。  
※加速から減速へ切り替わる際は、間に1秒間の惰行が入ります。
